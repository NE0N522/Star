# starDrop — Telegram Stars

Статическая мобильная витрина для Telegram Mini App. Сайт считает стоимость по фиксированному курсу **1 звезда = 1,50 ₽**, показывает тарифы и готовит сообщение админу @op_star.

## Важно для оплаты внутри Telegram

Telegram требует проводить оплату цифровых товаров и услуг внутри ботов и Mini Apps через Telegram Stars. Поэтому в Telegram Mini App реквизиты Сбера не показываются: пока бот не подключён к оплате, кнопка ведёт к админу для уточнения заказа. При настройке бота нужно подключить Telegram Stars invoices. Официальное правило: https://core.telegram.org/bots/payments-stars.

Если страницу открыть вне Telegram, заполненные реквизиты Сбера включат описанный ниже перевод и обращение к админу.

## Перед публикацией

1. Откройте `config.js`.
2. Заполните `sberRequisites` номером карты или телефоном для перевода.
3. При желании заполните `recipientName` именем получателя.
4. Разместите папку сайта на HTTPS-хостинге.
5. Подключите URL сайта к Telegram-боту как Mini App.

Пока реквизиты пустые, сайт честно показывает, что их нужно запросить у администратора. Значения в `config.js` доступны посетителям сайта — указывайте там только реквизиты, которые предназначены для получения переводов.

## Как проходит заказ вне Telegram

Покупатель выбирает пакет, вводит Telegram-юзернейм, переводит сумму на Сбер и нажимает кнопку связи с администратором. Откроется чат @op_star с готовым текстом заказа. Покупатель отправляет сообщение и прикрепляет фото чека в этом чате.

Сайт не принимает и не пересылает чеки самостоятельно. Для автоматической передачи чеков или уведомлений нужен сервер и подключённый бот.

## Акция «Медведь»

Окно акции объясняет условие: приглашённый друг покупает пакет на 100 звёзд и при обращении к @op_star сообщает юзернейм пригласившего. Подарок выдается за каждого такого друга, число приглашений не ограничено. Внутри Telegram Mini App юзернейм покупателя подставляется и его можно скопировать из окна акции.

## Локальный просмотр

Откройте `index.html` в браузере. Стили и логика находятся в `styles.css` и `app.js`. Telegram SDK включается при наличии интернета; вне Telegram сайт использует светлую/тёмную тему устройства.
